# Checkpoint Template

Use this structure when updating `PROJECT_STATE.md` / `HISTORY.md`.

```markdown
## YYYY-MM-DD HH:MM TZ — <short checkpoint title>

Repository:
Branch:
PR:
Work item:
Logical role:

Completed:
- ...

Verification:
- command/check → result

Decisions:
- none / ADR links

Blockers:
- ...

Next exact action:
1. ...

Do not redo:
- ...

Remote pushed:
- yes/no
```

A useful checkpoint tells the next model what **not** to repeat as well as what to do next.
