# Glossary

- **Authority:** pipeline/workflow sonucunu değiştirme yetkisi.
- **Artifact:** node/gate/model çıktısı.
- **Binding:** logical role ↔ provider/model/effort eşlemesi.
- **Candidate:** henüz authoritative doğrulanmamış bulgu.
- **Contract:** role/input/output/protocol davranış sözleşmesi.
- **Debate/Council:** bağımsız görüş + reconciliation protokolü.
- **Evidence:** finding/kararı destekleyen source/deterministic veri.
- **Finding:** doğrulanmış veya adjudication bekleyen problem/risk.
- **Gate:** geçilmesi gereken kontrol.
- **Independence group:** reviewer bağımsızlığını koruyan binding/provider grubu.
- **Lineage/Digital Thread:** requirement → decision → task → code → test → release → runtime ilişkisi.
- **Logical role:** model isminden bağımsız görev/authority sözleşmesi.
- **Node:** workflow graph birimi.
- **Promotion:** shadow rolün primary kullanım için kabul edilmesi.
- **Replay:** geçmiş state/event ile yeniden yürütme.
- **Role package:** prompt + contracts + tools + permissions + evidence + authority + bindings.
- **Shadow:** authority taşımayan benchmark/gözlem çalışması.
