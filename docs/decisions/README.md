## ADR kuralı

Yeni ADR:
- context/problem,
- considered alternatives,
- decision,
- rationale/trade-offs,
- consequences,
- affected requirements/work items,
- status

içermelidir.

Değişen karar eski ADR'yi sessizce düzenlemek yerine mümkünse yeni ADR ile supersede edilir.
